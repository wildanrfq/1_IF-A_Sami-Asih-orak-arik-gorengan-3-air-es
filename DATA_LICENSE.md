# Lisensi dan Atribusi Data

Dataset **Online Retail** berlisensi **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

- Sumber: https://archive.ics.uci.edu/dataset/352/online+retail
- Penyumbang: Daqing Chen, School of Engineering, London South Bank University (5 November 2015)
- Sitasi: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33
- Data hanya dipakai untuk keperluan akademik; atribusi dicantumkan pada Daftar Pustaka laporan.
- Berkas data mentah tidak disertakan di repositori. Unduh dengan `python scripts/download_data.py`.
